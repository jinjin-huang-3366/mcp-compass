# Security

MCP Compass handles untrusted ecosystem metadata and will eventually inspect generated/third-party MCP implementations. Security design is therefore part of the product, not a later add-on.

See `docs/SECURITY.md` for the current threat model and sandbox requirements.

Do not publish vulnerabilities, credentials, tokens, cookies, or private integration details in issues or pull requests.
Use GitHub's [private security advisory flow](https://github.com/jinjin-huang-3366/mcp-compass/security/advisories/new)
to report a vulnerability. Include the affected component, impact, and minimal reproduction without live credentials
or sensitive user data.
